Latihan mengolah API publik dan menyajikan data mentah menjadi grafik yang
mudah dibaca. Saya memakai Open-Meteo agar tidak memerlukan API key, lalu
menambahkan cache lokal untuk menghemat permintaan.

Tantangan utamanya adalah menjaga tampilan tetap tenang meski data yang datang
cukup banyak. Grafik hanya menampilkan metrik utama, detail lain disembunyikan
di balik panel yang bisa dibuka.
